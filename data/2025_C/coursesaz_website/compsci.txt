INTRODUCTION TO COMPUTER SCIENCE.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nIntroduction to Computer Science is a 3-credit hour **breadth** CS course. We cover several topics in this course to help students understand how computers work, e.g., binary numbers, Boolean logic and gates, circuit design, machine language, computer hardware, assembly, operating systems, networking, the Internet protocols, cybersecurity, data science, machine learning, and robotics.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI101">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>1. Demonstrate how data is represented in computers</li><li>2. Define the building blocks and organization of computer hardware</li><li>3. Describe the differences between machine, assembly, and high-level languages</li><li>4. Design an efficient algorithm and analyze its time/space complexity</li><li>5. Implement algorithms that solve problems</li><li>6. Explain how the Internet works</li><li>7. Detail how an operating system manages processes</li><li>8. Evaluate whether one is keeping data private</li><li>9. Categorize the different threats to computer systems</li><li>10. Perform the data science process</li><li>11. Explain the Turing test and how one defines intelligence</li><li>12. Categorize the different types of machine learning algorithms</li><li>13. Describe key computer ethics topics</li><li>14. Recognize the impact of computing on the world</li><li>15. Design and program Python applications,</li><li>16. Write loops and decision statements in Python,</li><li>17. Use lists, tuples, sets, dictionaries, and strings in Python,</li><li>18. Define the structure/components of a Python program,</li><li>19. Write functions and pass arguments in Python,</li><li>20. Write code that reads/writes files in Python,</li><li>21. Design object-oriented programs with Python classes, and</li><li>22. Read (trace) basic Python code.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI102. CSCI 102 is a 1-credit hour programming course in Python that is (A) extremely valuable for those who have never programmed and (B) required for some majors (e.g., MechE). While CSCI 102 is not required for some majors, students with little (or no) prior programming experience are strongly encouraged to enroll.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI102">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>Design and program Python applications</li><li>Write loops and decision statements in Python</li><li>Use lists, tuples, sets, dictionaries, and strings in Python</li><li>Define the structure/components of a Python program</li><li>Write functions and pass arguments in Python</li><li>Write code that reads/writes files in Python</li><li>Design object-oriented programs with Python classes</li><li>Read (trace) basic Python code</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI128.  COMPUTER SCIENCE FOR STEM.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nIntroduction to programming. Intended for students with no prior experience. Teaches basic programming constructs including data types, conditionals, loops, file I/O, functions, and objects in Python 3. Also covers topics vital to STEM computing, such as data science, best practices for code development, and software ethics. Prerequisite: None Co-requisite: None.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI128">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>Analyze a simple empirical problem, break it down into smaller more manageable components, and design algorithmic solutions to these subproblems</li><li>Implement an existing prompt, plan, or design into programmatically correct Python code that produces the expected text, file, or graph output</li><li>Communicate in the language of programming with a computer and other programmers through code reading, writing, and critique</li><li>Critically discuss and reflect on the role technology has in modern society, and the positive and negative impacts their software may have on future users</li><li>Model how basic numeric and non-numeric data is represented in a computer; identify when, why, and how these physical representations diverge from their conceptual equivalents</li><li>Navigate and utilize a computer file system through a GUI, the text console, and code</li><li>Demonstrate effective debugging practices in an IDE to find, characterize, and correct code errors</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI195.  CS@MINES BRIDGE SEMINAR COURSE.  1.0 Semester Hr.</strong></p>\n<p class="courseblockdesc">\n</p>\nThe purpose of this course is to support Bridge students for success in CS@Mines. Through this course, students will: 1.\tEngage in activities that show how computing changes the world and impacts daily lives,  2.\tDelve into a some of the foundational computer science topics (e.g., Binary Numbers, Networking, Operating Systems, Cybersecurity, Cyber Physical Systems, Artificial Intelligence, Machine Learning, Data Science, Bioinformatics, Robotics), and  3.\tExplore different career paths in the computer science industry.   Most importantly, this course will offer students the opportunity to build relationships with their cohort and their program advisors (e.g., Bridge Program Director, Graduate Program Manger),  as well as be a source of strength for each other. Prerequisite: Current CS@Mines Bridge Student .<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI195">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>1. Describe a breadth of foundational computer science topics and how they relate to emphasis areas in computing.</li><li>2. Implement networking and relationship building techniques within their cohort and other like-minded students.</li><li>3. Explain the importance of personal development tools and preparedness for careers in computing (e.g., imposter syndrome, the elevator pitch, resume building, navigating career day).</li><li>4. Summarize the different types of careers that exist in the computer science field.</li><li>5. Analyze the specific fields in computer science that are of most interest for deeper exploration and potential degree focus area.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI198. INDEPENDENT STUDY.  1-6 Semester Hr.</strong></p>\n<p class="courseblockdesc">\n</p>\n(I, II) Individual research or special problem projects supervised by a faculty member, when a student and instructor agree on a subject matter, content, and credit hours. Prerequisite: &quot;Independent Study&quot; form must be completed and submitted to the Registrar. Variable credit; 1 to 6 credit hours. Repeatable for credit.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI199">View Course Learning Outcomes</a></p>\n</div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI200.  FOUNDATIONAL PROGRAMMING CONCEPTS &amp; DESIGN.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nThis course teaches students C++, how to manage memory properly &amp; efficiently at run time, the principles of object-oriented programming, and how to create an algorithm using data structures &amp; abstraction to solve a problem.  Recursive data structures &amp; algorithms will be constructed &amp; analyzed when solving problems.  Initial principal components of software engineering and design will be introduced and used when drafting a solution to a problem.  Programs will be developed using a command line interface. Prerequisite: CSCI101 or CSCI128.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI200">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>L1. Design an algorithm to solve a problem by breaking the overarching problem into smaller modular components using abstraction and object-oriented design with inheritance.</li><li>L2. Translate the algorithm into a program using proper C++ syntax and fundamental programming constructs (e.g. control structures, I/O, classes).</li><li>L3. Recite &amp; apply frequently used Linux command line commands and compile a program using a command line build system.</li><li>L4. Diagram memory usage, dynamically allocate &amp; deallocate objects at run-time using &quot;The Big Three,&quot; and trace the call stack of a program\xe2\x80\x99s run-time.</li><li>L5. Define recursion and construct common recursive data structures (e.g. linked list, stack, queue) &amp; algorithms (e.g. search &amp; sort).</li><li>L6. Diagram &amp; construct dynamically allocated data structures (e.g. array, vector, string), recursive data structures, (e.g. linked list, stack, queue), and implement common list operations (e.g. traversal, insertion, removal)</li><li>L7. Define &quot;Big-O&quot; notation, list complexities in increasing order, and analyze an algorithm to compute its run-time performance &amp; memory complexities</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI210.  SYSTEMS PROGRAMMING.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nThe Systems Programming course will teach students how to become proficient with using a Linux operating system from the command line and programming Linux systems. Topics will include: shell scripts; compiling and linking programs; redirecting input and output; controlling jobs from the command line; using advanced SSH functions such as port forwarding and dynamic proxying; file system hierarchy;, package management; kernel compilation; network management; C programming with dynamic memory management, function pointers, c-style polymorphism, recursive functions, and data structures; learning how to use a code repository maintenance tool, such as git, from the command line effectively; security, privacy, and encryption concepts; inter-process communication and client-server architectures.  Prerequisite: CSCI200.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI210">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>1. Identify, select, and apply appropriate Linux commands for file, process, and network management.</li><li>2. Utilize the command line by designing and creating shell scripts; compiling and linking programs; redirecting input and output of processes; and executing commands for controlling jobs/processes.</li><li>3. Explain the purpose of and apply advanced SSH functions such as port forwarding, dynamic proxying, effectively.</li><li>4. Administer a Linux system applying knowledge of the file system hierarchy, package management, kernel compilation, and network management.</li><li>5. Design and write C programs composed of dynamic memory management, function pointers, c-style polymorphism, recursive functions, and data structures.</li><li>6. Examine the capabilities of a code repository maintenance tool, such as git, through command line version control.</li><li>7. Select and implement appropriate security, privacy, and encryption protocols at the operating system level.</li><li>8. Design and implement programs with client-server architecture using inter-process communication.</li><li>9. Discuss and apply appropriate time and project management strategies through the development of multiple substantial programming projects throughout the semester.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI220.  DATA STRUCTURES AND ALGORITHMS.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nThis course teaches students the design and construction of data structures such as hash tables, trees, heaps, and graphs, analysis of operations on data structures, and design and analysis of algorithms on data structures such as graph search and minimum spanning tree algorithms.  Applications of data structures and algorithms on them are discussed in the context of computer systems.  Students will further refine programming skills in C++ by producing software implementations of selected data structures and algorithms. Prerequisite: CSCI200 with a C- or better, CSCI358 or MATH334.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI220">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>Apply algorithmic analysis methods including solving recurrence relations, the \xe2\x80\x9cunifying theorem,\xe2\x80\x9d and amortized analysis to compute best case, worst case, and average case run-time complexity of algorithms and operations on data structures; and discuss trade-offs between time and space complexity.</li><li>Describe hash tables and write software implementing a hash table; explain and evaluate collision handling methods in the context of storage hierarchies; and assess the relative merits of different hash functions for data types such as strings and integers.</li><li>Describe search trees and their applications and write software implementing a search tree; explain and contrast trees such as red-black or AVL trees, splay trees, b-trees, and radix tries in application contexts such as operating systems, network routing, and databases.</li><li>Describe heaps and priority queues and write software implementing a heap; apply priority queues to problem domains such as data compression and operating systems.</li><li>Define unweighted, weighted, undirected, and directed graphs and explain data structures for storing graphs; explain and analyze algorithms for graph discovery and classification.</li><li>Explain and analyze algorithms on graphs for finding shortest paths and minimum spanning trees; write software implementing graph algorithms; discuss applications of graph algorithms.</li><li>Demonstrate professional conduct with respect to communication and time management.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI250.  PYTHON-BASED COMPUTING: BUILDING A SENSOR SYSTEM.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nThis course will teach students the skills needed for data collection, analysis, and visualization on a small embedded device (e.g., Raspberry Pi). Students will learn basic Linux, Python, and the programming skills needed to control the hardware and associated sensors. This hands-on course includes a baseline project, four introductory projects (e.g., acoustic, acceleration, magnetic field, optical), and a final Capstone project. The Capstone project will have students create their own application using the techniques learned during the first half of the semester; students will then present their Capstone project through a formal presentation, write-up, and demonstration.  We suggest the student take &quot;Introduction to Computer Science&quot; before this course. Prerequisite: CSCI128. Co-requisite: MATH213, PHGN200.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI250">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>1. Create, navigate, and manage files and directory structures using basic Linux shell commands.</li><li>2. Describe the functionality and purpose of the individual components of the Raspberry Pi Hardware.</li><li>3. Install the Raspian operating system onto the Raspberry Pi Hardware and setup basic configuration parameters.</li><li>4. Download, install, and develop programs using the Spyder Integrated Development Environment (IDE) on the Raspberry Pi Hardware.</li><li>5. Develop and run basic Python functions and programs in the Linux environment to collect data from sensors using the Raspberry Pi Hardware (e.g., acoustic, acceleration, magnetic field, optical).</li><li>6. INTRODUCTION TO THE LINUX OPERATING SYSTEM.  1.0 Semester Hr.</strong></p>\n<p class="courseblockdesc">\n</p>\nIntroduction to the Linux Operating System will teach students how to become proficient with using a Linux operating system from the command line. Prerequisite: CSCI200 or CSCI261.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=CSCI274">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>unchanged</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>CSCI290.
