#breadcrumb -->\n\t\t<!--/htdig_noindex-->\n\n\t\t<div id="content" role="main">\n\t\t\t<h1 class="page-title">FEA PROFESSIONAL (FEGN)</h1>\n\n\n\n\n\n<div id="textcontainer" class="page_content">\n\n<div class="sc_sccoursedescs">\n<div class="courseblock">\n<p class="courseblocktitle"><strong>FEGN525.  ADVANCED FEA THEORY &amp; PRACTICE.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nThis course examines the theory and practice of finite element analysis. Direct methods of deriving the FEA governing equations are addressed as well as more advanced techniques based on virtual work and variational methods. Common 1D, 2D, and 3D element formulations are derived, and key limitations examined. Matlab is used extensively to build intuition for FEA solution methods and students will create their own 2D FEA code by the end of the course. The commercial FEA software Abaqus is introduced with hands-on examples and Matlab solutions are compared to Abaqus for model validation.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=FEGN525">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>Define DOF.</li><li>Recall three different approaches for developing governing equations in FEA and list typical applications for each.</li><li>Apply FEA governing equations to solve2D structural analysis by hand using symbolic math in Matlab.</li><li>Explain and execute a mesh convergence study.</li><li>Define the isoparametric element formulation and use shape functions to derive isoparametric elements for 2D and 3D applications.</li><li>Recall numbers and locations of integration points for different element types.</li><li>List and explain limitations of common 2D and 3D elements.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>FEGN526.  STATIC AND DYNAMIC APPLICATIONS IN FEA.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nThis course emphasizes proficiency with commercial FEA software for solution of practical static, quasistatic, and dynamic structural problems. Common 1D, 2D, and 3D elements are examined in the context of linear solution techniques. Students will explore efficient methods for model construction and solution with commercial tools (the Abaqus FEA software). Emphasis will also be placed on verification, validation, and reporting standards for effective application of FEA software tools. Online course. Prerequisite: FEGN525.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=FEGN526">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>Explain the difference between implicit and explicit solvers for static, quasi-static, and dynamic analyses.</li><li>Compare the pros and cons of solutions obtained using implicit and explicit solvers for static, quasi-static, and dynamic analyses.</li><li>Perform a 1D, 2D, or 3D structural analysis with or without symmetry (axi, cyclic).</li><li>Request desired outputs from commercial FEA software and recall the difference between field and history output data types.</li><li>Setup an FEA analysis to request desired output variables defined spatially and temporally.</li><li>Use commercial FEA software pre-processor to visualize results from an FEA solution.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>FEGN527.  NONLINEAR APPLICATIONS IN FEA.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nThis course explores common nonlinearities frequently encountered in structural applications of FEA. Students will gain proficiency in modeling geometric nonlinearity (large strains), boundary nonlinearity due to contact, and material nonlinearity (creep, rate dependence, plasticity, temperature effects, residual stress). The commercial FEA software Abaqus is used for hands-on experience. Online course. Prerequisite: FEGN526.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=FEGN527">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>Recall and explain the three most common sources of nonlinearity in an FEA simulation.</li><li>Perform an FEA simulation including large strains and finite rotations.</li><li>Execute an FEA simulation including contact and compare several strategies for modeling contact interactions.</li><li>Develop and apply nonlinear models for hyperelastic, viscoelastic, and elastic-plastic materials.</li><li>Use an FEA simulation to compute residual stresses in a part following plastic deformation.</li><li>Construct a clear report to communicate work performed for an FEA simulation.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>FEGN528.  FEA FOR ADVANCED DESIGN APPLICATIONS.  3.0 Semester Hrs.</strong></p>\n<p class="courseblockdesc">\n</p>\nIn this course students will learn the automation tools and methods necessary for effective application of FEA on advanced design problems. Strategies for parametric analysis, performance optimization, and consideration of statistical uncertainty will be examined using Python scripting and commercial automation software. Online course. Prerequisite: FEGN526.<br/>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=FEGN528">View Course Learning Outcomes</a></p>\n<p class="courseblockextra noindent"><div class="bubble-hidden"><h6 class="toggle">View Course Learning Outcomes</h6><ul><li>Apply Python scripting to automate parametric analysis of a part or assembly using commercial FEA software.</li><li>Apply Abaqus Isight to automate parametric analysis of a part or assembly using commercial FEA software.</li><li>Use Python scripting or other software tools to automate extraction and post-processing of results from commercial FEA software.</li><li>Apply automation tools to perform optimization and probabilistic analysis using commercial FEA software.</li><li>Construct a clear report to communicate work performed for an FEA simulation.</li></ul></div></p></div><div class="courseblock">\n<p class="courseblocktitle"><strong>FEGN599.  INDEPENDENT STUDY.  0.5-6 Semester Hr.</strong></p>\n<p class="courseblockdesc">\n</p>\n<p class="notinpdf coursedraw-hidden"><a href="/search/?search=FEGN599">View Course Learning Outcomes</a></p>\n</div><div class="courseblock">\n<p class="courseblocktitle"><strong>FEGN599.
